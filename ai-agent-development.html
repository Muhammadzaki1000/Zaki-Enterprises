FAQ

AI Agent Development: common questions

What is an AI agent?

A program that uses an AI model to understand a request and carry out defined steps, often using tools.

Can an agent act without approval?

Only where we agree it is safe. Sensitive actions keep a person in the loop.

What do you need to start?

A clear task, example requests and the information the agent should use.
